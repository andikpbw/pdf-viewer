# pdf_viewer Example

Interactive showcase application demonstrating the features of `pdf_viewer`:

* Multi-page vector PDF rendering & `PdfDocumentBuilder` generation
* Full-text search with live match highlighting (`"Humanize AI"`, `"Vector"`, `"Annotation"`)
* Interactive markup tools (Highlighter, Freehand Ink, Sticky Notes) with Undo/Redo
* Live page thumbnails, Outlines/Bookmarks drawer, and Reading Color Modes (Normal, Night, Sepia, Grayscale)

Proudly supported by [Humanize AI](https://humanize.id).

## Running the Example

```bash
cd example
flutter run
```
